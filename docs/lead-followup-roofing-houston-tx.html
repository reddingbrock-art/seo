FAQ

Common Questions About Roofing Lead Follow-Up in Houston

How many follow-ups does it send?

We typically set up 3–5 touchpoints over 14 days: day-of text, day-3 email, day-7 text, day-14 email. If they book before then, it stops. You can adjust the sequence based on what converts best for your area.

Can I customize what it says?

Yes. We write it to match your tone—whether you're aggressive, friendly, professional, or all three. You review every message before it goes live. Changes take minutes.

What if a lead asks to stop?

They can unsubscribe with one click. We handle compliance automatically so you're never at risk. Respect boundaries, keep your reputation clean.

Does this work with my current CRM?

If you're in GoHighLevel or Pipedrive or similar, yes. If you're on something else, we integrate through Zapier or set up a clean manual import weekly. Most roofing shops move into GoHighLevel because it handles everything—calls, texts, emails, scheduling.
